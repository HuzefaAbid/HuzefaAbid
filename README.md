### 📂 Featured Projects

*An enterprise knowledge-sharing and Q&A platform featuring AI telemetry, answer verification, and HR analytics.*
* **AI Telemetry & Insights:** Integrated **Google Gemini** to automatically analyze unresolved threads, highlight knowledge gaps, detect trending tag spikes, and generate monthly digest newsletters.
* **AI Answer Verification:** Real-time evaluation engine that assesses answer quality with completeness scores (1-10), constructive feedback, and policy violation detection.
* **Full-Stack Architecture:** Built with **React 19, TypeScript, Vite, and Tailwind CSS** on the frontend, paired with **Node.js, Express, and MongoDB** protected by rate limiting, secure HTTP headers, and JWT cookie sessions.
* **Operational Dashboard:** HR admin console tracking question resolution rates, department health metrics, and employee contribution leaderboards.

* **Microservices Design:** Leveraged **Docker** and **Apache Kafka** to communicate between the Node.js backend and Python ML microservices.
* **Continuous Integration:** Structured automated testing and deployment workflows using **Jenkins** CI/CD pipelines.

#### 🏥 **[Healthcare Management System](https://github.com/HuzefaAbid/healthcare-management-system)**

* **Web Security:** Configured **Helmet.js**, express-rate-limiters, and input sanitization to block DDoS, XSS, and injection vectors.

* **Backend Framework:** Built with **Express 5.x** and **Mongoose**, featuring full user verification and JWT token lifecycles.
* **Granular Organization:** Allows administrators to assign team members to projects, update permissions, track task priorities, and manage subtasks.
